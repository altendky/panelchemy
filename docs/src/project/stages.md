# Work Stages

The [GitHub issue list](https://github.com/altendky/panelchemy/issues) tracks
delivery and current state. This document records the intended sequence.

1. [Repository foundation](https://github.com/altendky/panelchemy/issues/2):
   package layout, project contract, reproducible tools,
   CI, and repository settings.
2. [Color separation and silhouette](https://github.com/altendky/panelchemy/issues/3):
   reusable API/CLI, reviewable normalization,
   panel boundary, visible masks, and cumulative supports.
3. [Local browser workflow](https://github.com/altendky/panelchemy/issues/4):
   input selection, adjustable parameters, intermediate
   previews, and reproducible saved output through the shared core.
4. [Outward-tapered relief](https://github.com/altendky/panelchemy/issues/5):
   configurable physical geometry with preserved feature
   tops, supporting material bands, and a vertical exterior.
5. [Validation and export](https://github.com/altendky/panelchemy/issues/6):
   checked solids, registered material volumes, manifests,
   and a verified slicer import.
6. [Physical profile and coupon](https://github.com/altendky/panelchemy/issues/7):
   choose real print settings and evaluate artwork
   features at final XY scale before full-panel printing.
7. [Later deployment](https://github.com/altendky/panelchemy/issues/8):
   assess the actual runtime and provide reproducible hosted
   artifacts while preserving local operation.

Separation enables both the local browser work and relief work. Validation
depends on relief geometry. A physical coupon additionally needs user-selected
size and printer settings. Deployment follows a useful local workflow; no
domain, hosting runtime, or publication target is selected yet.

[Optional contour approximation](https://github.com/altendky/panelchemy/issues/14)
addresses dense raster outlines between relief construction and full-size export
evaluation. It is off by default and must retain islands and counters while
reporting its physical tolerance and original/selected outline comparison.
